# Repülőjegy Foglalási Rendszer

Pythonban készült egyszerű repülőjegy foglalási rendszer.

## Funkciók
- Jegy foglalása
- Foglalás lemondása
- Foglalások listázása

## Osztályok
- Jarat
- BelfoldiJarat
- NemzetkoziJarat
- LegiTarsasag
- JegyFoglalas

## Indítás

```bash
python main.py
```
